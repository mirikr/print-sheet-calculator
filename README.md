# Раскладка на лист

Калькулятор для препресса: сколько изделий поместится на одном печатном листе и сколько листов нужно на тираж. Схема листа рисуется сразу.

**Открыть сайт:** https://mirikr.github.io/print-sheet-calculator/

Сайт статический: `index.html`, `styles.css` и `app.js`, без сборки и зависимостей. Чтобы открыть его, достаточно открыть `index.html` в браузере или включить GitHub Pages.

## Что учитывается

| Параметр | Что это |
|---|---|
| **Печатный лист** | Формат листа (ширина × длина). Есть готовые форматы (SRA3, A3, 330×488, 700×1000 и др.) или можно задать свой. |
| **Непечатаемые поля** | Края листа, куда машина не печатает (захват, клапан). Каждая сторона задаётся отдельно, по умолчанию 15 мм слева и справа, 10 мм сверху и снизу. |
| **Основная часть изделия** | Готовый размер после резки (обрезной формат). |
| **Обрезаемая часть** | Вылеты, которые уходят под нож. Каждая сторона задаётся отдельно или одинаково со всех сторон. |
| **Размер до обреза** | Основная часть + обрезаемая. Можно ввести и этот размер: основная часть пересчитается. |
| **Резка** | *У каждого изделия* (двойной рез, можно добавить зазор) или *общий рез* (изделия встык, вылет только по краю блока). |
| **Поворот на 90°** | Можно запретить, если важно направление волокон. |
| **Тираж и запас** | Сколько нужно изделий и запас на приладку в процентах. |

## Что считает

- **Изделий на листе.** Сравниваются три варианта: без поворота, с поворотом на 90° и комбинированный (основной блок плюс полоса повёрнутых изделий, всё режется на гильотине). Лучший вариант помечен, любой из них можно выбрать.
- **Листов на тираж** с учётом запаса и **лишние изделия**.
- **Заполнение** листа и печатной области в процентах.
- **Технические данные**: габарит раскладки, расстояние от края листа до первого реза, свободное место и сколько миллиметров не хватает до следующего ряда.

## Схема

- Штриховка показывает непечатаемые поля, пунктир — границу печатной области.
- Розовым показана обрезаемая часть, голубым — основная часть, жёлтым — повёрнутые изделия.
- Метки реза рисуются только там, где их можно напечатать.
- Если навести курсор на изделие, появятся его номер и координаты реза от левого верхнего угла листа.
- **SVG** сохраняет схему в масштабе 1:1 в миллиметрах, её можно открыть в Illustrator или CorelDRAW.
- **Печать** даёт техкарту: схему вместе с параметрами.
- **Ссылка** копирует адрес со всеми текущими параметрами, чтобы отправить его коллеге.

В полях работают стрелки ↑/↓: шаг 1 мм, с Shift шаг 10 мм, с Alt шаг 0,1 мм.
